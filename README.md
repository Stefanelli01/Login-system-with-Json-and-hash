# Python User Authentication

A simple authentication system built with Python to practice user registration, login validation, password hashing, and JSON file handling.

## Features

- User registration and login
- Password hashing with SHA-256
- JSON-based data storage
- Duplicate email prevention
- Basic error handling

## Technologies

- Python 3
- `hashlib`
- `json`

## Usage

```bash
python main.py
```

Follow the interactive menu to register a user, log in, or exit the application.

## Security Notice

This project is for educational purposes only. Security measures are not fully implemented, and SHA-256 alone is not suitable for securely storing passwords in production environments.

The goal is to learn fundamental authentication concepts and build a foundation for larger, more secure projects.
